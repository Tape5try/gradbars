# Migrating to v1.2.0 / 升级到 v1.2.0

Replace all 22 runtime modules together. Existing calls need no new options; the v1.1.1 signed-theme and baseline notes still apply. Download links to published v1.1.0 manuals do not describe this unreleased development snapshot.

Opt in independently to measured legend layout, builtin duplicate diagnostics or area contrast. Explicit text colors bypass auto contrast; place `text color=auto` after themes when needed. Use the new spark-target command with a fixed/named scale, keeping targets separate from observations. There is no new compound CSV/native-table type. See [contracts, examples and limits](readability.md).
