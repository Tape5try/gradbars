\medskip
\textbf{Reading this manual.} Start with data semantics, then choose a graphic.
Appearance and evaluation rules precede the dedicated table interface; complete
examples and the reference follow. Rendered examples use the source shown beside
or below them. All data are illustrative. The English and Chinese manuals cover
the same interfaces; their section and example numbers are independent.

\medskip
\textbf{v1.1.1 maintenance (2026-10-27, development snapshot; not released).}
This patch repairs extraction, archives and documentation references while
retaining existing interfaces and default data semantics. Explicit header-legend
helpers are added, with \key{table legend=true|false} controlling their swatch row.
Continuous Heat legends
have decorative semitransparent white separators between 256 base-color strips;
the texture differs from v1.1.0 and does not indicate categories or bins.
Full regressions require the development checkout; trimmed source packages
validate unpacking and documentation builds only.
