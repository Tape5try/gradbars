{\small\color{manualMuted}\textbf{阅读指南}\par
本手册把安装说明、参数、77 个编号示例、选型指南与常见问题集中在同一文档中。
其中包括六个应用表格，以及双栏论文、跨页长表、黑白打印和幻灯片的真实排版案例。
浅黄色区域展示实际排版效果，浅紫色区域展示生成该效果的源码。
全书按入门、图形、外观、专属表格、案例与参考六部分组织。源码中的空行用于区分示例。
示例框内的效果与源码来自同一段代码，避免两者脱节。\par
\vspace{3mm}
适用于 gradbars 1.1.1。示例数据仅用于演示，不代表真实实验结果。\par}

\medskip
\textbf{v1.1.1 维护说明（2026-10-27，开发版尚未正式发布）。}
本版修复源码提取、归档与文档引用，保留已有接口和默认数据语义。
新增显式调用的表头组装图例命令，使用 \key{table legend=true|false} 控制图例行显隐。
连续 Heat 图例在 256 段底色之间带有装饰性半透明白色细纹；与 v1.1.0 相比外观有变化，
细纹不表示分类或分箱。完整回归使用开发仓库，缺少 tests 的精简源码包仅验证解包与文档构建。
